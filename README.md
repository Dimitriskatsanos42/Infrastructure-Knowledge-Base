# 🛠️ Infrastructure-Knowledge-Base
*Προσωπικό Project Μάθησης & Πρακτικής Εξάσκησης*

---

## 📌 Σχετικά με αυτό το Repository
Αυτό το repository είναι ένα καθαρά προσωπικό project. Το δημιούργησα για να λειτουργεί ως το ψηφιακό μου σημειωματάριο και να καταγράφω την καθημερινή μου μελέτη, τις δοκιμές μου και την πρακτική μου εξάσκηση.

Στόχος μου είναι η συνεχής μάθηση και η σταδιακή εξέλιξη μέσα από πρακτική εφαρμογή. Οτιδήποτε προσθέτω εδώ αποτυπώνει την προσωπική μου πορεία και τον τρόπο που κατανοώ τις τεχνολογίες.

## 📚 Τι θα περιλαμβάνει
Με την πάροδο του χρόνου, το υλικό θα εμπλουτίζεται σταδιακά. Το πλάνο μου είναι να μελετήσω, να κάνω πρακτική και να καλύψω σε αυτό το repository.

---

## 🎯 Τι περιλαμβάνει η Βάση Γνώσεων
Το υλικό είναι χωρισμένο σε καθαρές κατηγορίες και ανανεώνεται συνεχώς:

* **IT Support & Operations:** Βασικές διαδικασίες Helpdesk και διαχείριση υπολογιστών.
* **Διαχείριση Συστημάτων (Windows & Linux):** Παρακολούθηση πόρων, διεργασιών και ρυθμίσεων του OS.
* **Δίκτυα (Networking):** Έλεγχος συνδεσιμότητας, IP, DNS, Routing και θυρών.
* **Active Directory & Cloud:** Διαχείριση χρηστών και πολιτικών σε τοπικά δίκτυα (On-Premises) και Hybrid περιβάλλοντα (Microsoft 365 / Entra ID).
* **Ασφάλεια (Cybersecurity):** Endpoint hardening, έλεγχος Event Logs και βασική ανίχνευση ύποπτης δραστηριότητας.
* **Scripting & Αυτοματοποίηση:** Μικρά scripts σε PowerShell και Bash για την αυτοματοποίηση καθημερινών εργασιών.

## 💡 Η Φιλοσοφία του Project
Η προσέγγισή μου είναι απλή: πρώτα κατανοώ τη θεωρία, μετά τη δοκιμάζω στην πράξη μέσω labs και στη συνέχεια κρατάω καθαρές και οργανωμένες σημειώσεις.

Κάθε οδηγός ή script σε αυτό το repository δεν είναι απλώς μια λίστα εντολών, αλλά ένα πρακτικό παράδειγμα που βασίζεται σε πραγματικά σενάρια.

---

## 🚀 Στόχος & Εξέλιξη
Ο στόχος μου δεν είναι η απλή αποστήθιση εντολών, αλλά η ουσιαστική κατανόηση του τρόπου με τον οποίο αλληλεπιδρούν μεταξύ τους οι βασικές τεχνολογίες της σύγχρονης υποδομής.

Το Infrastructure-Knowledge-Base αποτελεί ένα ζωντανό και εξελισσόμενο project (living documentation). Κάθε σημείωση, δοκιμή ή script που προστίθεται, αντικατοπτρίζει τη συνεχή μελέτη, την πρακτική εξάσκηση και τη σταδιακή εξέλιξή.

Μέσα από αυτό το project αποτυπώνεται με διαφάνεια η πορεία μου προς την κατανόηση και διαχείριση πραγματικών περιβαλλόντων πληροφορικής.

# 🖥️ Windows System Administration & Networking

Μια συλλογή από σημειώσεις, οδηγούς και εντολές αναφοράς για τη διαχείριση συστημάτων Windows, το δίκτυο, την αντιμετώπιση προβλημάτων και την αυτοματοποίηση εργασιών.

Το repository απευθύνεται σε system administrators, τεχνικούς υποστήριξης (helpdesk / IT support) και φοιτητές που θέλουν μια γρήγορη και οργανωμένη βάση γνώσης.

---

## 📚 Περιεχόμενα

| Αρχείο | Περιγραφή |
|--------|-----------|
| [`windows-commands-reference.md`](./windows-commands-reference.md) | Οδηγός αναφοράς με βασικές και χρήσιμες εντολές των Windows (CMD, PowerShell, δίκτυο, δίσκοι, χρήστες, υπηρεσίες). |
| [`windows-sysadmin-extra.md`](./windows-sysadmin-extra.md) | Επιπλέον εργαλεία, τεχνικές και συμβουλές για την καθημερινή διαχείριση συστημάτων Windows. |
| [`windows-advanced-troubleshooting-automation.md`](./windows-advanced-troubleshooting-automation.md) | Προχωρημένη αντιμετώπιση προβλημάτων και αυτοματοποίηση εργασιών με scripts. |
| [`windows-virtualization-clustering-infrastructure.md`](./windows-virtualization-clustering-infrastructure.md) | Virtualization, clustering και υποδομές (Hyper-V, Failover Clustering κ.ά.). |

## 🚀 Προτεινόμενη σειρά ανάγνωσης

1. **`windows-commands-reference.md`** – ξεκινήστε από τα βασικά.
2. **`windows-sysadmin-extra.md`** – εμπλουτίστε τις γνώσεις σας με επιπλέον εργαλεία.
3. **`windows-advanced-troubleshooting-automation.md`** – περάστε σε διάγνωση προβλημάτων και αυτοματοποίηση.

## 🧰 Θεματικές Ενότητες

- Εντολές CMD και PowerShell
- Διαχείριση χρηστών, ομάδων και δικαιωμάτων
- Δικτύωση (TCP/IP, DNS, DHCP, διαγνωστικά εργαλεία)
- Διαχείριση υπηρεσιών, διεργασιών και δίσκων
- Αντιμετώπιση προβλημάτων και ανάλυση logs
- Αυτοματοποίηση με scripts
- Virtualization (Hyper-V) και Clustering
- Σχεδιασμός και διαχείριση υποδομών

## ⚠️ Σημαντική Σημείωση

Πολλές από τις εντολές απαιτούν **δικαιώματα διαχειριστή (Run as Administrator)**. Δοκιμάστε πάντα πρώτα σε περιβάλλον δοκιμών (lab / virtual machine) πριν τις εφαρμόσετε σε παραγωγικά συστήματα και φροντίστε να υπάρχουν πρόσφατα αντίγραφα ασφαλείας.

# Διαχείριση Χρηστών & Δικαιωμάτων στο Linux

Πρακτικός οδηγός για τη διαχείριση χρηστών, ομάδων και δικαιωμάτων αρχείων σε συστήματα Linux — καλύπτει καθημερινές διαχειριστικές εργασίες καθώς και πρακτικές ασφαλείας.

---

## 1. Χρήστες και Ομάδες

### 1.1 Βασικά Αρχεία
| Αρχείο | Σκοπός |
|------|---------|
| `/etc/passwd` | Πληροφορίες λογαριασμού χρήστη (username, UID, GID, home dir, shell) |
| `/etc/shadow` | Κρυπτογραφημένοι κωδικοί και πολιτικές λήξης κωδικών |
| `/etc/group` | Ορισμοί ομάδων και μελών |
| `/etc/sudoers` | Κανόνες δικαιωμάτων sudo (επεξεργασία μόνο με `visudo`) |

### 1.2 Δημιουργία και Διαχείριση Χρηστών

```bash
# Δημιουργία νέου χρήστη με home directory
sudo useradd -m -s /bin/bash newuser

# Ορισμός / αλλαγή κωδικού
sudo passwd newuser

# Τροποποίηση υπάρχοντος χρήστη (π.χ. αλλαγή shell)
sudo usermod -s /bin/zsh newuser

# Κλείδωμα / ξεκλείδωμα λογαριασμού
sudo usermod -L newuser      # κλείδωμα
sudo usermod -U newuser      # ξεκλείδωμα

# Διαγραφή χρήστη (και του home directory του)
sudo userdel -r newuser
```

### 1.3 Ομάδες

```bash
# Δημιουργία ομάδας
sudo groupadd developers

# Προσθήκη υπάρχοντος χρήστη σε ομάδα (δευτερεύουσα ομάδα)
sudo usermod -aG developers newuser

# Αλλαγή κύριας ομάδας χρήστη
sudo usermod -g developers newuser

# Εμφάνιση ομάδων στις οποίες ανήκει ένας χρήστης
groups newuser
id newuser
```

> **Συμβουλή:** Χρησιμοποιείς πάντα το `-aG` (append) με το `usermod`. Αν χρησιμοποιήσεις `-G` χωρίς `-a`, αντικαθιστάς όλες τις υπάρχουσες δευτερεύουσες ομάδες του χρήστη.

## 2. Βασικά Δικαιώματα (rwx)

Κάθε αρχείο/φάκελος έχει τρία σύνολα δικαιωμάτων: **owner** (ιδιοκτήτης), **group** (ομάδα), **others** (λοιποί).

```
-rwxr-xr--  1 dimitris devs  1024 Aug  6 10:00 deploy.sh
```

| Σύμβολο | Σημασία |
|--------|---------|
| `r` (4) | Ανάγνωση (Read) |
| `w` (2) | Εγγραφή (Write) |
| `x` (1) | Εκτέλεση (Execute) — ή "είσοδος" για φακέλους |

### 2.1 chmod — Αλλαγή Δικαιωμάτων

```bash
# Συμβολική μορφή
chmod u+x script.sh        # προσθήκη δικαιώματος εκτέλεσης για τον owner
chmod g-w file.txt         # αφαίρεση δικαιώματος εγγραφής από την ομάδα
chmod o=r file.txt         # ορισμός "others" μόνο για ανάγνωση
chmod a+r file.txt         # προσθήκη ανάγνωσης για όλους

# Αριθμητική (octal) μορφή
chmod 755 script.sh        # rwxr-xr-x
chmod 644 file.txt         # rw-r--r--
chmod 700 private_dir/     # rwx------

# Αναδρομικά (recursive)
chmod -R 750 /var/www/app
```

### 2.2 chown / chgrp — Αλλαγή Ιδιοκτησίας

```bash
sudo chown dimitris file.txt          # αλλαγή owner
sudo chown dimitris:devs file.txt     # αλλαγή owner και group
sudo chgrp devs file.txt              # αλλαγή μόνο της ομάδας
sudo chown -R www-data:www-data /var/www/app
```

## 3. Ειδικά Δικαιώματα

| Bit | Αριθμητικά | Συμβολικά | Επίδραση |
|-----|---------|----------|--------|
| SUID | `4000` | `chmod u+s file` | Το αρχείο εκτελείται με τα δικαιώματα του **ιδιοκτήτη** (π.χ. `/usr/bin/passwd`) |
| SGID | `2000` | `chmod g+s dir` | Τα νέα αρχεία μέσα σε ένα φάκελο κληρονομούν την **ομάδα** του φακέλου |
| Sticky bit | `1000` | `chmod +t dir` | Μόνο ο ιδιοκτήτης του αρχείου (ή ο root) μπορεί να διαγράψει/μετονομάσει αρχεία μέσα σε κοινόχρηστο φάκελο (π.χ. `/tmp`) |

```bash
# Παράδειγμα: κοινόχρηστος φάκελος ομάδας όπου τα νέα αρχεία κληρονομούν την ομάδα
# και μόνο ο ιδιοκτήτης κάθε αρχείου μπορεί να το διαγράψει
sudo chmod 2775 /srv/team_shared
sudo chmod +t /srv/team_shared
```

Έλεγχος για ειδικά bits:

```bash
ls -l /usr/bin/passwd
# -rwsr-xr-x  → έχει οριστεί SUID
```

## 4. Access Control Lists (ACLs)

Τα βασικά δικαιώματα υποστηρίζουν μόνο έναν owner και μία group. Τα **ACLs** επιτρέπουν λεπτομερή δικαιώματα για πολλαπλούς χρήστες/ομάδες στο ίδιο αρχείο.

```bash
# Προβολή ACLs
getfacl file.txt

# Παραχώρηση δικαιώματος ανάγνωσης/εγγραφής σε συγκεκριμένο χρήστη
setfacl -m u:alice:rw file.txt

# Παραχώρηση δικαιώματος μόνο ανάγνωσης σε συγκεκριμένη ομάδα
setfacl -m g:auditors:r file.txt

# Ορισμός default ACL σε φάκελο (κληρονομείται από νέα αρχεία)
setfacl -d -m u:alice:rw /srv/shared/

# Αφαίρεση συγκεκριμένης ACL καταχώρησης
setfacl -x u:alice file.txt

# Αφαίρεση όλων των ACLs
setfacl -b file.txt
```

## 5. umask — Προεπιλεγμένα Δικαιώματα

Το `umask` ορίζει ποια bits δικαιωμάτων **αφαιρούνται** από τα προεπιλεγμένα (666 για αρχεία, 777 για φακέλους) όταν δημιουργούνται νέα αρχεία/φάκελοι.

```bash
umask            # εμφάνιση τρέχουσας τιμής
umask 022        # προεπιλογή: αρχεία → 644, φάκελοι → 755
umask 077         # περιοριστικό: αρχεία → 600, φάκελοι → 700
```

Για να γίνει μόνιμο, πρόσθεσέ το στο `~/.bashrc` ή στο `/etc/profile`.

## 6. sudo και Αύξηση Δικαιωμάτων (Privilege Escalation)

### 6.1 Ασφαλής επεξεργασία κανόνων sudo

```bash
sudo visudo
```

### 6.2 Συνηθισμένες καταχωρήσεις sudoers

```
# Πλήρη δικαιώματα sudo σε χρήστη
dimitris ALL=(ALL:ALL) ALL

# Δικαίωμα σε ομάδα να τρέχει συγκεκριμένη εντολή χωρίς κωδικό
%devs ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart nginx

# Δικαίωμα σε χρήστη να τρέχει εντολές μόνο ως συγκεκριμένος χρήστης
backupuser ALL=(dbadmin) /usr/local/bin/backup.sh
```

### 6.3 Καλές Πρακτικές

- Ποτέ μην επεξεργάζεσαι απευθείας το `/etc/sudoers` — χρησιμοποίησε πάντα το `visudo` (ελέγχει τη σύνταξη πριν αποθηκεύσει).
- Προτίμησε να δίνεις δικαιώματα σε **ομάδες**, όχι σε μεμονωμένους χρήστες.
- Χρησιμοποίησε το `NOPASSWD` με φειδώ, μόνο για συγκεκριμένες, ασφαλείς, μη-διαδραστικές εντολές.
- Έλεγξε τη χρήση του sudo μέσω `/var/log/auth.log` (Debian/Ubuntu) ή `/var/log/secure` (RHEL/CentOS).

```bash
# Έλεγχος τι επιτρέπεται να τρέξει ένας χρήστης
sudo -l -U dimitris
```

## 7. Έλεγχος & Αντιμετώπιση Προβλημάτων

```bash
# Εύρεση αρχείων που ανήκουν σε συγκεκριμένο χρήστη
find / -user dimitris -type f 2>/dev/null

# Εύρεση αρχείων με δικαίωμα εγγραφής από όλους (πιθανός κίνδυνος ασφαλείας)
find / -xdev -type f -perm -0002 2>/dev/null

# Εύρεση αρχείων SUID στο σύστημα
find / -perm -4000 -type f 2>/dev/null

# Έλεγχος τελευταίων συνδέσεων
last -a

# Έλεγχος τρέχοντων συνδεδεμένων χρηστών
who
w
```

## 8. Γρήγορος Οδηγός Αναφοράς

| Εργασία | Εντολή |
|------|---------|
| Προσθήκη χρήστη | `useradd -m -s /bin/bash user` |
| Ορισμός κωδικού | `passwd user` |
| Προσθήκη χρήστη σε ομάδα | `usermod -aG group user` |
| Αλλαγή δικαιωμάτων | `chmod 755 file` |
| Αλλαγή ιδιοκτήτη | `chown user:group file` |
| Προβολή ACLs | `getfacl file` |
| Ορισμός ACL | `setfacl -m u:user:rw file` |
| Επεξεργασία κανόνων sudo | `visudo` |
| Προβολή δικαιωμάτων sudo | `sudo -l -U user` |

## Βασικά Συμπεράσματα

- Χρησιμοποίησε **ομάδες** αντί για μεμονωμένα δικαιώματα όπου είναι δυνατόν — ευκολότερη διαχείριση σε μεγαλύτερη κλίμακα.
- Χρησιμοποίησε τα **SUID/SGID/sticky bit** μόνο σε συγκεκριμένες, κατανοητές περιπτώσεις χρήσης· μπορούν να δημιουργήσουν κινδύνους ασφαλείας αν εφαρμοστούν λανθασμένα.
- Τα **ACLs** είναι η σωστή λύση όταν τα βασικά δικαιώματα owner/group/other δεν προσφέρουν αρκετή ευελιξία.
- Έλεγχε πάντα τις αλλαγές στο `sudoers` με το `visudo` ώστε να αποφύγεις να κλειδωθείς έξω από το σύστημα.
- Έλεγχε τακτικά για αρχεία εγγράψιμα από όλους και απρόσμενα SUID binaries, ως μέρος της τακτικής υγιεινής ασφαλείας.

# Διαχείριση Διεργασιών (Process Management) στο Linux

Πρακτικός οδηγός για την παρακολούθηση, τον έλεγχο και τη διαχείριση διεργασιών σε συστήματα Linux — από βασικές εντολές μέχρι προγραμματισμό εργασιών με cron.

---

## 1. Τι είναι μια Διεργασία (Process)

Κάθε πρόγραμμα που εκτελείται στο σύστημα αντιστοιχεί σε μία ή περισσότερες διεργασίες. Κάθε διεργασία έχει:

| Χαρακτηριστικό | Περιγραφή |
|------|---------|
| **PID** | Process ID — μοναδικός αριθμός αναγνώρισης |
| **PPID** | Parent Process ID — η διεργασία που τη δημιούργησε |
| **UID/GID** | Ο χρήστης/ομάδα με τα δικαιώματα των οποίων τρέχει |
| **State** | Κατάσταση (running, sleeping, stopped, zombie κ.λπ.) |
| **Priority / Nice value** | Προτεραιότητα εκτέλεσης στον scheduler |

---

## 2. Προβολή Διεργασιών

### 2.1 ps — Στιγμιότυπο διεργασιών

```bash
ps aux                     # όλες οι διεργασίες, όλων των χρηστών
ps -ef                     # εναλλακτική μορφή (System V style)
ps -u dimitris              # διεργασίες συγκεκριμένου χρήστη
ps aux --sort=-%cpu | head  # top 10 διεργασίες σε χρήση CPU
ps aux --sort=-%mem | head  # top 10 διεργασίες σε χρήση μνήμης
```

Βασικές στήλες του `ps aux`:

| Στήλη | Σημασία |
|-------|---------|
| `PID` | Process ID |
| `%CPU` | Ποσοστό χρήσης επεξεργαστή |
| `%MEM` | Ποσοστό χρήσης μνήμης |
| `STAT` | Κατάσταση (R=running, S=sleeping, Z=zombie, T=stopped) |
| `COMMAND` | Η εντολή που εκτελείται |

### 2.2 top / htop — Παρακολούθηση σε πραγματικό χρόνο

```bash
top                 # ενσωματωμένο εργαλείο παρακολούθησης
htop                 # πιο φιλικό, διαδραστικό (χρειάζεται εγκατάσταση)
```

Χρήσιμα πλήκτρα μέσα στο `top`:
- `P` → ταξινόμηση κατά CPU
- `M` → ταξινόμηση κατά μνήμη
- `k` → kill διεργασίας (ζητά PID)
- `q` → έξοδος

### 2.3 pstree — Δέντρο διεργασιών

```bash
pstree              # ιεραρχική προβολή γονέων/παιδιών διεργασιών
pstree -p            # με τα PIDs
```

## 3. Τερματισμός Διεργασιών

### 3.1 kill — Αποστολή σήματος με βάση PID

```bash
kill <PID>           # στέλνει SIGTERM (15) — ζητά "ευγενικό" τερματισμό
kill -9 <PID>         # στέλνει SIGKILL (9) — άμεση, βίαιη διακοπή
kill -HUP <PID>       # SIGHUP — συχνά χρησιμοποιείται για reload ρυθμίσεων
```

| Σήμα | Νούμερο | Σημασία |
|------|---------|---------|
| `SIGTERM` | 15 | Ζητάει τερματισμό, επιτρέπει cleanup (default) |
| `SIGKILL` | 9 | Άμεσος, βίαιος τερματισμός — δεν μπορεί να αγνοηθεί |
| `SIGHUP` | 1 | Επανεκκίνηση/reload configuration |
| `SIGSTOP` | 19 | Παύση διεργασίας |
| `SIGCONT` | 18 | Συνέχιση παυμένης διεργασίας |

### 3.2 pkill / killall — Τερματισμός με βάση όνομα

```bash
pkill nginx           # τερματίζει διεργασίες με όνομα "nginx"
pkill -u dimitris      # τερματίζει όλες τις διεργασίες συγκεκριμένου χρήστη
killall firefox        # τερματίζει όλες τις διεργασίες με αυτό το όνομα
```

> **Προσοχή:** Το `-9` (SIGKILL) να χρησιμοποιείται μόνο σαν τελευταία λύση — δεν επιτρέπει στη διεργασία να αποθηκεύσει δεδομένα ή να κλείσει σωστά.

## 4. Foreground, Background & Job Control

```bash
long_command &         # εκτέλεση στο background
jobs                    # προβολή τρεχουσών background εργασιών του shell
fg %1                   # επαναφορά job 1 στο foreground
bg %1                   # συνέχιση job 1 στο background
Ctrl+Z                  # παύση τρέχουσας foreground διεργασίας
Ctrl+C                  # αποστολή SIGINT (διακοπή)
```

### 4.1 nohup & disown — Διεργασίες ανεξάρτητες από το terminal

```bash
nohup ./long_script.sh &   # η διεργασία συνεχίζει μετά το logout
disown -h %1                 # αφαιρεί τη job από τον έλεγχο του τρέχοντος shell
```

## 5. Προτεραιότητα Διεργασιών (nice / renice)

Η τιμή **nice** καθορίζει την προτεραιότητα scheduling μιας διεργασίας: εύρος **-20 (υψηλότερη προτεραιότητα)** έως **19 (χαμηλότερη)**.

```bash
nice -n 10 ./script.sh       # εκκίνηση με χαμηλότερη προτεραιότητα
renice -n 5 -p <PID>          # αλλαγή προτεραιότητας τρέχουσας διεργασίας
renice -n -5 -p <PID>         # απαιτεί root για αρνητικές τιμές (υψηλότερη προτεραιότητα)
```

## 6. Zombie & Orphan Processes

- **Zombie process**: διεργασία που έχει τερματίσει αλλά ο γονέας της δεν έχει διαβάσει ακόμα την κατάσταση εξόδου (`wait()`). Εμφανίζεται με state `Z`.
- **Orphan process**: διεργασία της οποίας ο γονέας τερμάτισε πριν από αυτή· υιοθετείται συνήθως από τη διεργασία `init`/`systemd` (PID 1).

```bash
ps aux | grep 'Z'          # εντοπισμός zombie διεργασιών
```

> Οι zombies δεν μπορούν να τερματιστούν με `kill` — πρέπει να αντιμετωπιστεί ο γονέας τους (π.χ. με restart της γονικής υπηρεσίας).

## 7. Προγραμματισμός Εργασιών (Cron & at)

### 7.1 cron — Επαναλαμβανόμενες εργασίες

```bash
crontab -e            # επεξεργασία cron jobs τρέχοντος χρήστη
crontab -l             # προβολή τρεχόντων cron jobs
crontab -r             # διαγραφή όλων των cron jobs
```

Μορφή εγγραφής crontab:

```
* * * * * command_to_run
│ │ │ │ │
│ │ │ │ └── Ημέρα εβδομάδας (0-6, 0=Κυριακή)
│ │ │ └──── Μήνας (1-12)
│ │ └────── Ημέρα μήνα (1-31)
│ └──────── Ώρα (0-23)
└────────── Λεπτό (0-59)
```

Παραδείγματα:

```bash
0 3 * * * /usr/local/bin/backup.sh          # κάθε μέρα στις 03:00
*/15 * * * * /usr/local/bin/check.sh         # κάθε 15 λεπτά
0 0 * * 0 /usr/local/bin/weekly_report.sh    # κάθε Κυριακή τα μεσάνυχτα
```

Συστημικά cron jobs (system-wide) βρίσκονται στο `/etc/cron.d/`, `/etc/crontab`, και στους φακέλους `/etc/cron.daily/`, `/etc/cron.weekly/` κ.λπ.

### 7.2 at — Μία εφάπαξ εργασία σε συγκεκριμένη ώρα

```bash
at 22:00                     # εισαγωγή εντολών διαδραστικά, Ctrl+D για αποθήκευση
echo "/usr/local/bin/backup.sh" | at now + 1 hour
atq                            # προβολή προγραμματισμένων εργασιών
atrm <job_id>                  # ακύρωση εργασίας
```

## 8. Παρακολούθηση Πόρων Συστήματος

```bash
uptime                # load average συστήματος
free -h                # χρήση μνήμης (human-readable)
vmstat 1 5              # στατιστικά μνήμης/CPU/IO ανά δευτερόλεπτο, 5 φορές
iostat                 # στατιστικά I/O δίσκου (χρειάζεται sysstat)
lsof -p <PID>            # ανοιχτά αρχεία μιας διεργασίας
lsof -i :80              # ποια διεργασία χρησιμοποιεί μια θύρα (π.χ. 80)
```

---

## 9. Γρήγορος Οδηγός Αναφοράς

| Εργασία | Εντολή |
|------|---------|
| Προβολή όλων των διεργασιών | `ps aux` |
| Παρακολούθηση σε πραγματικό χρόνο | `top` / `htop` |
| Δέντρο διεργασιών | `pstree -p` |
| Τερματισμός με PID | `kill -9 <PID>` |
| Τερματισμός με όνομα | `pkill <name>` |
| Εκτέλεση σε background | `command &` |
| Αποσύνδεση από terminal | `nohup command &` |
| Αλλαγή προτεραιότητας | `renice -n <value> -p <PID>` |
| Επεξεργασία cron jobs | `crontab -e` |
| Εφάπαξ προγραμματισμένη εργασία | `at <time>` |
| Ποια διεργασία χρησιμοποιεί μια θύρα | `lsof -i :<port>` |

---

## Βασικά Συμπεράσματα

- Χρησιμοποίησε πρώτα `SIGTERM` (`kill` χωρίς `-9`) πριν καταφύγεις σε `SIGKILL` — δίνει στη διεργασία ευκαιρία για σωστό τερματισμό.
- Το `nohup` και το `disown` είναι απαραίτητα για μακροχρόνιες εργασίες που πρέπει να συνεχίσουν μετά την αποσύνδεση από το terminal — εναλλακτικά, προτίμησε `systemd` services ή `screen`/`tmux` για production περιβάλλοντα.
- Οι **zombie processes** δεν είναι πρόβλημα από μόνες τους σε μικρό αριθμό, αλλά μεγάλος αριθμός τους υποδεικνύει bug στη γονική διεργασία.
- Χρησιμοποίησε `cron` για επαναλαμβανόμενες εργασίες και `at` για εφάπαξ προγραμματισμένες εργασίες.
- Εργαλεία όπως `lsof` και `vmstat` είναι πολύτιμα για troubleshooting προβλημάτων απόδοσης ή "κολλημένων" πόρων.

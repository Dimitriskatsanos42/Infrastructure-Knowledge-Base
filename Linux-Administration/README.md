- Filesystem Hierarchy (FHS) — τι υπάρχει σε κάθε φάκελο
- Permissions (chmod/chown) — read/write/execute, octal notation
- Users & Groups — δημιουργία, διαχείριση, sudo
- systemd — πώς ξεκινούν και σταματούν services
- Bash scripting — αυτοματοποίηση επαναλαμβανόμενων εργασιών

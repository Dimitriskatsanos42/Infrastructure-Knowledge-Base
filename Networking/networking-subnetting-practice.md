## 📋 1. Quick Reference — CIDR Cheat Sheet

| CIDR | Subnet Mask | # Subnets (από /24) | # Usable Hosts |
|:---:|---|:---:|---:|
| /24 | 255.255.255.0 | 1 | 254 |
| /25 | 255.255.255.128 | 2 | 126 |
| /26 | 255.255.255.192 | 4 | 62 |
| /27 | 255.255.255.224 | 8 | 30 |
| /28 | 255.255.255.240 | 16 | 14 |
| /29 | 255.255.255.248 | 32 | 6 |
| /30 | 255.255.255.252 | 64 | 2 |
| /31 | 255.255.255.254 | 128 | 0 (point-to-point, RFC 3021) |
| /32 | 255.255.255.255 | 256 | 1 (host route) |

## ✨ 2. Η Μέθοδος του "Magic Number"

Η γρηγορότερη πρακτική μέθοδος χωρίς αριθμομηχανή:

**Magic Number = 256 − (η τιμή του τελευταίου μη-μηδενικού octet της μάσκας)**

Το Magic Number σου δίνει το **"βήμα"** (block size) μεταξύ διαδοχικών subnets.

### Παράδειγμα: 192.168.1.0/27
```
Μάσκα /27 = 255.255.255.224
Magic Number = 256 − 224 = 32

→ Τα subnets πηδάνε ανά 32:
192.168.1.0, 192.168.1.32, 192.168.1.64, 192.168.1.96,
192.168.1.128, 192.168.1.160, 192.168.1.192, 192.168.1.224
```

### Βήματα για κάθε άσκηση
1. Βρες το octet όπου "δουλεύει" η μάσκα (το πρώτο octet της μάσκας που δεν είναι 255 ή 0).
2. Υπολόγισε το Magic Number = 256 − (τιμή μάσκας σε εκείνο το octet).
3. Μέτρησε ανά Magic Number για να βρεις όλα τα Network Addresses.
4. Broadcast Address = επόμενο Network Address − 1.
5. Usable Hosts = ό,τι είναι ανάμεσα σε Network και Broadcast.

## 📝 3. Ασκήσεις Βασικού Επιπέδου (Λυμένες)

### Άσκηση 1
**Δίκτυο:** 192.168.10.0/26 — Βρες: Network Address, Broadcast Address, Usable Range, # Hosts

**Λύση:**
```
/26 = 255.255.255.192 → Magic Number = 256 − 192 = 64

Subnets: 192.168.10.0, 192.168.10.64, 192.168.10.128, 192.168.10.192

Το 192.168.10.0/26 είναι το πρώτο subnet:
Network Address:   192.168.10.0
Broadcast Address: 192.168.10.63   (επόμενο subnet 192.168.10.64, μείον 1)
Usable Range:      192.168.10.1 – 192.168.10.62
# Usable Hosts:    2^6 − 2 = 62
```

### Άσκηση 2
**Δίκτυο:** 10.20.30.140/28 — Σε ποιο subnet ανήκει αυτή η IP;

**Λύση:**
```
/28 = 255.255.255.240 → Magic Number = 256 − 240 = 16

Subnets στο τρίτο octet... όχι, εδώ η μάσκα δουλεύει στο 4ο octet:
0, 16, 32, 48, 64, 80, 96, 112, 128, 144, ...

Η IP .140 πέφτει ανάμεσα στο 128 και το 144:
Network Address:   10.20.30.128
Broadcast Address: 10.20.30.143
Usable Range:      10.20.30.129 – 10.20.30.142
# Usable Hosts:    2^4 − 2 = 14
```

### Άσκηση 3
**Απαίτηση:** Χρειάζεσαι subnet για 100 hosts. Ποια είναι η μικρότερη μάσκα που ταιριάζει;

**Λύση:**
```
Χρειαζόμαστε: 2^h − 2 ≥ 100
2^7 − 2 = 126 ✓ (αρκεί)
2^6 − 2 = 62  ✗ (δεν αρκεί)

Άρα χρειαζόμαστε 7 bits για hosts → Μάσκα = /25 (32 − 7 = 25)
Μάσκα: 255.255.255.128, παρέχει 126 usable hosts
```

## 🧩 4. Ασκήσεις VLSM (Λυμένες)

**VLSM (Variable Length Subnet Masking)** — χρησιμοποιούμε διαφορετικά μεγέθη subnet στο ίδιο δίκτυο, ανάλογα με τις πραγματικές ανάγκες κάθε τμήματος, ώστε να μη σπαταλάμε IPs.

### Άσκηση: Σχεδίασε VLSM για το δίκτυο 192.168.100.0/24

**Απαιτήσεις:**
| Τμήμα | Απαιτούμενοι Hosts |
|---|:---:|
| Sales | 60 |
| HR | 25 |
| IT | 10 |
| Point-to-Point link (Router-Router) | 2 |

**Λύση (πάντα ξεκινάμε από τη ΜΕΓΑΛΥΤΕΡΗ απαίτηση):**

**Βήμα 1 — Sales (60 hosts):**
```
Χρειαζόμαστε 2^h − 2 ≥ 60 → h=6 (2^6−2=62) → Μάσκα /26 (255.255.255.192)
Subnet: 192.168.100.0/26
Usable range: 192.168.100.1 – 192.168.100.62
Broadcast: 192.168.100.63
```

**Βήμα 2 — HR (25 hosts):**
```
Χρειαζόμαστε 2^h − 2 ≥ 25 → h=5 (2^5−2=30) → Μάσκα /27 (255.255.255.224)
Επόμενο διαθέσιμο block μετά το Sales: 192.168.100.64
Subnet: 192.168.100.64/27
Usable range: 192.168.100.65 – 192.168.100.94
Broadcast: 192.168.100.95
```

**Βήμα 3 — IT (10 hosts):**
```
Χρειαζόμαστε 2^h − 2 ≥ 10 → h=4 (2^4−2=14) → Μάσκα /28 (255.255.255.240)
Επόμενο διαθέσιμο block: 192.168.100.96
Subnet: 192.168.100.96/28
Usable range: 192.168.100.97 – 192.168.100.110
Broadcast: 192.168.100.111
```

**Βήμα 4 — Point-to-Point (2 hosts):**
```
Χρειαζόμαστε 2^h − 2 ≥ 2 → h=2 (2^2−2=2) → Μάσκα /30 (255.255.255.252)
Επόμενο διαθέσιμο block: 192.168.100.112
Subnet: 192.168.100.112/30
Usable range: 192.168.100.113 – 192.168.100.114
Broadcast: 192.168.100.115
```

### 📊 Συγκεντρωτικός Πίνακας VLSM

| Τμήμα | Subnet | Μάσκα | Usable Range | Broadcast |
|---|---|---|---|---|
| Sales | 192.168.100.0 | /26 | .1 – .62 | .63 |
| HR | 192.168.100.64 | /27 | .65 – .94 | .95 |
| IT | 192.168.100.96 | /28 | .97 – .110 | .111 |
| P2P Link | 192.168.100.112 | /30 | .113 – .114 | .115 |
| **Διαθέσιμο για μελλοντική χρήση** | 192.168.100.116 – .255 | — | — | — |

## 🎯 5. Ασκήσεις "Ποιο Subnet Ανήκει" (Λυμένες)

Πολύ συχνός τύπος ερώτησης σε συνέντευξη: *"Δίνεται μια IP και μια μάσκα — ανήκουν δύο συσκευές στο ίδιο δίκτυο;"*

### Άσκηση
**PC-A:** 172.16.45.10 /22
**PC-B:** 172.16.47.200 /22

Βρίσκονται στο ίδιο subnet;

**Λύση:**
```
/22 = 255.255.252.0 → Magic Number στο 3ο octet = 256 − 252 = 4

Subnets στο 3ο octet: 0, 4, 8, 12, ..., 44, 45→ όχι multiple, ψάχνουμε το block που περιέχει το 45:
...40, 44, 48...
Το 45 πέφτει στο block 44-47 (44 + 4 - 1 = 47)

PC-A (172.16.45.10) → Subnet: 172.16.44.0/22 (εύρος 3ου octet: 44-47)
PC-B (172.16.47.200) → Επίσης εντός 44-47 → Subnet: 172.16.44.0/22

✅ ΝΑΙ, ανήκουν στο ίδιο subnet (172.16.44.0/22, εύρος 172.16.44.1–172.16.47.254)
```

## 🌐 6. IPv6 Subnetting — Βασικά

Στο IPv6, το subnetting είναι πιο απλό γιατί σχεδόν πάντα δουλεύουμε σε ορισμένα, "καθαρά" όρια (nibble boundaries — κάθε hex χαρακτήρας = 4 bits).

### Τυπική δομή IPv6 διεύθυνσης
```
2001:0db8:85a3:0000 : 0000:8a2e:0370:7334
└──────┬──────┘└─┬─┘  └──────────┬──────────┘
  Global Routing  Subnet ID      Interface ID (host portion)
    Prefix (/48)    (16 bits)       (64 bits, /64)
```

### Πρακτικός κανόνας
- Ένα **/48** δίνεται συνήθως σε έναν οργανισμό.
- Κάθε **/64** είναι ένα μεμονωμένο subnet (LAN) — δεν χρειάζεται DHCP, μπορεί να χρησιμοποιήσει SLAAC.
- Από ένα /48, έχεις **2^16 = 65,536 διαθέσιμα /64 subnets** — πρακτικά ανεξάντλητο για τους περισσότερους οργανισμούς.

### Παράδειγμα κατανομής από 2001:db8:1234::/48
```
2001:db8:1234:0001::/64  → VLAN 10 (Sales)
2001:db8:1234:0002::/64  → VLAN 20 (HR)
2001:db8:1234:0003::/64  → VLAN 30 (IT)
```
> Δεν χρειάζεται πολύπλοκος μαθηματικός υπολογισμός σαν το IPv4 VLSM — απλά αυξάνεις το subnet ID (το τέταρτο hextet) κατά ένα για κάθε νέο /64.

## 📚 7. Ασκήσεις Χωρίς Λύση — Για Εξάσκηση

Δοκίμασε να τις λύσεις μόνος/η σου πριν δεις τις λύσεις στο Κεφάλαιο 8.

**Άσκηση Α:** Δίνεται 10.1.1.0/29. Βρες Network, Broadcast, Usable Range, # Hosts.

**Άσκηση Β:** Δίνεται η IP 172.20.88.53/23. Σε ποιο subnet ανήκει;

**Άσκηση Γ:** Χρειάζεσαι 4 subnets από το δίκτυο 192.168.5.0/24, όλα ίδιου μεγέθους. Ποια μάσκα χρησιμοποιείς και ποια είναι τα 4 subnets;

**Άσκηση Δ (VLSM):** Σχεδίασε subnetting για το 10.10.0.0/22 με απαιτήσεις: Τμήμα 1 = 200 hosts, Τμήμα 2 = 100 hosts, Τμήμα 3 = 50 hosts, 2× Point-to-Point links.

**Άσκηση Ε:** Δύο συσκευές: 192.168.1.65/26 και 192.168.1.130/26. Ίδιο subnet;

## ✅ 8. Λύσεις Κεφαλαίου 7

### Λύση Α
```
/29 = 255.255.255.248 → Magic Number = 8
Network Address: 10.1.1.0
Broadcast: 10.1.1.7
Usable Range: 10.1.1.1 – 10.1.1.6
# Hosts: 2^3 − 2 = 6
```

### Λύση Β
```
/23 = 255.255.254.0 → Magic Number στο 3ο octet = 2
Subnets στο 3ο octet: 0, 2, 4, ..., 86, 88, 90...
Το 88 είναι ήδη πολλαπλάσιο → Subnet: 172.20.88.0/23
Εύρος: 172.20.88.0 – 172.20.89.255
Broadcast: 172.20.89.255
```

### Λύση Γ
```
Χρειαζόμαστε 4 subnets → 2^n ≥ 4 → n=2 bits δανεισμένα
/24 + 2 bits = /26
Μάσκα: 255.255.255.192

Τα 4 subnets:
192.168.5.0/26   (.1–.62,   broadcast .63)
192.168.5.64/26  (.65–.126, broadcast .127)
192.168.5.128/26 (.129–.190, broadcast .191)
192.168.5.192/26 (.193–.254, broadcast .255)
```

### Λύση Δ
```
Ταξινόμηση από μεγαλύτερο σε μικρότερο:

Τμήμα 1 (200 hosts): χρειάζεται 2^8−2=254 → /24
  → 10.10.0.0/24 (usable: .1–.254)

Τμήμα 2 (100 hosts): χρειάζεται 2^7−2=126 → /25
  → 10.10.1.0/25 (usable: 10.10.1.1–10.10.1.126)

Τμήμα 3 (50 hosts): χρειάζεται 2^6−2=62 → /26
  → 10.10.1.128/26 (usable: 10.10.1.129–10.10.1.190)

P2P Link 1 (2 hosts): /30
  → 10.10.1.192/30 (usable: .193–.194)

P2P Link 2 (2 hosts): /30
  → 10.10.1.196/30 (usable: .197–.198)
```

### Λύση Ε
```
/26 = Magic Number 64 → Subnets: .0, .64, .128, .192

192.168.1.65  → ανήκει στο block 64-127 → Subnet 192.168.1.64/26
192.168.1.130 → ανήκει στο block 128-191 → Subnet 192.168.1.128/26

❌ ΟΧΙ, ΔΕΝ είναι στο ίδιο subnet — δεν μπορούν να επικοινωνήσουν
   απευθείας χωρίς router (Layer 3 device) ανάμεσά τους.
```

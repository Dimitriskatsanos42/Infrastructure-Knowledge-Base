## Επισκόπηση

Στην καθημερινή υποστήριξη IT, οι ίδιες διαγνωστικές εντολές εκτελούνται ξανά και ξανά σε κάθε ticket. Το **`HelpDesk-Tool.ps1`** συγκεντρώνει τους πιο συχνούς ελέγχους σε ένα ενιαίο, χρωματικά κωδικοποιημένο μενού και παράγει αναφορά έτοιμη για επισύναψη στο ticket, μειώνοντας τον χρόνο διάγνωσης και τα λάθη πληκτρολόγησης.

Το αποθετήριο περιλαμβάνει:

1. **Το εργαλείο αυτοματοποίησης** (`HelpDesk-Tool.ps1`).
2. **Τεχνικό οδηγό** με 20 εντολές, οργανωμένες ανά κατηγορία, με περιγραφή και πρακτικό σενάριο χρήσης.

---

## Χαρακτηριστικά

| # | Επιλογή μενού | Εντολές που εκτελούνται | Σκοπός |
|---|---------------|-------------------------|--------|
| 1 | Διάγνωση Δικτύου | `ipconfig`, `ping`, `nslookup` | Έλεγχος IP, συνδεσιμότητας και ανάλυσης DNS |
| 2 | Σύστημα & Δικαιώματα | `whoami`, `systeminfo` | Ταυτότητα χρήστη, ομάδες, έκδοση OS, boot time |
| 3 | Ενεργές Συνδέσεις | `netstat` | Εντοπισμός ύποπτης δικτυακής δραστηριότητας |
| 4 | Κατάσταση Firewall | `netsh` | Επιβεβαίωση ενεργών προφίλ τείχους προστασίας |
| 5 | Δημιουργία Αναφοράς | Όλα τα παραπάνω | Εξαγωγή σε αρχείο `.txt` στην Επιφάνεια Εργασίας για την τεκμηρίωση του ticket |

## Απαιτήσεις

- Windows 10 / 11 ή Windows Server 2016+
- PowerShell 5.1 ή νεότερο
- Δικαιώματα διαχειριστή (ορισμένες εντολές, π.χ. `netsh advfirewall`, απαιτούν αυξημένα δικαιώματα)

## Εγκατάσταση & Χρήση

```powershell
# 1. Κλωνοποίηση του αποθετηρίου
git clone <URL-του-αποθετηρίου>
cd <όνομα-φακέλου>

# 2. Εκτέλεση του εργαλείου (τρέχουσα συνεδρία μόνο)
powershell -ExecutionPolicy Bypass -File .\HelpDesk-Tool.ps1
```

> **Σημείωση:** Το `-ExecutionPolicy Bypass` ισχύει μόνο για τη συγκεκριμένη εκτέλεση και δεν αλλάζει μόνιμα την πολιτική του συστήματος. Πριν την εκτέλεση σε παραγωγικό περιβάλλον, ελέγξτε το περιεχόμενο του script και τη συμφωνία με τις πολιτικές της εταιρείας σας.

## Δείγμα Αναφοράς

Η **Επιλογή 5** αποθηκεύει ένα αρχείο `.txt` στην Επιφάνεια Εργασίας, το οποίο μπορεί να επισυναφθεί απευθείας στο ticket. Ενδεικτική δομή:

```text
===== HELP DESK REPORT =====
Computer : <ComputerName>
User     : <Domain\User>
Date     : <ημερομηνία/ώρα>

[1] Network Diagnostics
[2] System & User Info
[3] Active Connections
[4] Firewall Status
```

## Οδηγός: Οι 20 Βασικές Εντολές

Οι εντολές είναι οργανωμένες σε τέσσερις κατηγορίες. Οι περισσότερες εκτελούνται από Command Prompt ή PowerShell· όσες απαιτούν αυξημένα δικαιώματα σημειώνονται με 🔒.

### 🌐 1. Επίλυση Προβλημάτων Δικτύου

| # | Εντολή | Τι κάνει | Πρακτική χρήση στο Help Desk |
|---|--------|----------|------------------------------|
| 1 | `ipconfig /all` | Εμφανίζει πλήρη παραμετροποίηση TCP/IP (IP, Subnet, Gateway, DNS, MAC) | Έλεγχος αν το μηχάνημα έλαβε έγκυρη IP από DHCP ή αυτο-εκχωρημένη APIPA (`169.254.x.x`) |
| 2 | `ping <προορισμός>` | Στέλνει αιτήματα ICMP echo και μετρά συνδεσιμότητα και latency | `ping 8.8.8.8` για πρόσβαση στο διαδίκτυο· `ping <server>` για εσωτερική συνδεσιμότητα. *Προσοχή:* ένα firewall μπορεί να μπλοκάρει το ICMP |
| 3 | `nslookup <domain>` | Ερωτά DNS servers για την IP ενός domain (ή αντίστροφα) | Όταν ο χρήστης αναφέρει «δεν ανοίγει η ιστοσελίδα», διαπιστώνεται αν αποτυγχάνει η ανάλυση DNS |
| 4 | `tracert <προορισμός>` | Καταγράφει τη διαδρομή των πακέτων και κάθε ενδιάμεσο hop | Εντοπισμός του σημείου όπου πέφτει ή επιβραδύνεται η σύνδεση |
| 5 | `netstat -ano` | Εμφανίζει ενεργές συνδέσεις, ακροατές (listening ports) και το PID της κάθε διεργασίας | Έλεγχος ασφαλείας για επικοινωνία με ύποπτες εξωτερικές IP· το PID αντιστοιχίζεται με το `tasklist` |
| 6 | `getmac` | Επιστρέφει τη φυσική διεύθυνση MAC των προσαρμογέων | Παροχή MAC στην ομάδα δικτύων για port binding ή whitelisting |

### 💻 2. Διαχείριση Συστήματος & Χρηστών

| # | Εντολή | Τι κάνει | Πρακτική χρήση στο Help Desk |
|---|--------|----------|------------------------------|
| 7 | `whoami /all` | Εμφανίζει τον τρέχοντα χρήστη, το SID, τις ομάδες και τα προνόμια | Επιβεβαίωση προβλημάτων δικαιωμάτων ή συμμετοχής στους τοπικούς Administrators |
| 8 | `systeminfo` | Αναφορά για έκδοση OS, hardware, boot time και εγκατεστημένα hotfixes | Έλεγχος του «System Boot Time» για να επιβεβαιωθεί ότι έγινε πραγματική επανεκκίνηση |
| 9 | `net user` 🔒 | Εμφανίζει, δημιουργεί ή τροποποιεί τοπικούς λογαριασμούς | `net user <λογαριασμός> *` για επαναφορά κωδικού τοπικού λογαριασμού χωρίς GUI (ο κωδικός δεν εμφανίζεται κατά την πληκτρολόγηση) |
| 10 | `net localgroup administrators` | Εμφανίζει τους λογαριασμούς με δικαιώματα τοπικού διαχειριστή | Έλεγχος ότι δεν υπάρχει μη εξουσιοδοτημένη πρόσβαση διαχειριστή |
| 11 | `query user` | Εμφανίζει τις ενεργές συνεδρίες χρηστών (τοπικές ή RDP) | Έλεγχος για συνδεδεμένους χρήστες πριν από επανεκκίνηση server |

### 🛠️ 3. Επιδιόρθωση & Συντήρηση Συστήματος

| # | Εντολή | Τι κάνει | Πρακτική χρήση στο Help Desk |
|---|--------|----------|------------------------------|
| 12 | `sfc /scannow` 🔒 | System File Checker: σαρώνει τα προστατευμένα αρχεία συστήματος και επιδιορθώνει τα κατεστραμμένα από τοπική cached αντιγραφή | Τυχαία crashes, BSOD, χαμένες λειτουργίες συστήματος. Αν αποτύχει, τρέξτε πρώτα `DISM /Online /Cleanup-Image /RestoreHealth` και επαναλάβετε |
| 13 | `chkdsk /f /r` 🔒 | Ελέγχει το σύστημα αρχείων για σφάλματα (`/f`) και ανακτά δεδομένα από κατεστραμμένους τομείς (`/r`) | Παγώματα, ύποπτοι δίσκοι, κατεστραμμένα αρχεία. Στον δίσκο συστήματος προγραμματίζεται στην επόμενη επανεκκίνηση |
| 14 | `gpupdate /force` | Επιβάλλει άμεση ανανέωση των Group Policies του Active Directory | Άμεση εφαρμογή νέων πολιτικών, mapped drives ή αναπτύξεων λογισμικού χωρίς αποσύνδεση |
| 15 | `gpresult /r` | Εμφανίζει το Resultant Set of Policy (RSoP) για χρήστη και υπολογιστή | Διαπίστωση ποιες πολιτικές AD εφαρμόζονται ή μπλοκάρονται |
| 16 | `tasklist` | Εμφανίζει τις τρέχουσες διεργασίες και τη χρήση μνήμης | Εντοπισμός παγωμένων ή πολυπόρων διεργασιών (π.χ. CPU στο 100%) |
| 17 | `taskkill /f /im <όνομα.exe>` | Τερματίζει αναγκαστικά διεργασία με βάση το όνομα ή το PID (`/pid`) | `taskkill /f /im outlook.exe` για παγωμένο Outlook που αρνείται να κλείσει |

### 🛡️ 4. Ασφάλεια & Περιβάλλον

| # | Εντολή | Τι κάνει | Πρακτική χρήση στο Help Desk |
|---|--------|----------|------------------------------|
| 18 | `netsh advfirewall show allprofiles` 🔒 | Εμφανίζει την κατάσταση των προφίλ Windows Defender Firewall (Domain, Private, Public) | Επιβεβαίωση ότι το τείχος προστασίας δεν έχει απενεργοποιηθεί από τον χρήστη |
| 19 | `driverquery` | Εμφανίζει τους εγκατεστημένους drivers και τις ιδιότητές τους (`/v` για λεπτομέρειες) | Εντοπισμός παλιών ή προβληματικών drivers τρίτων (π.χ. αποσυνδέσεις Wi-Fi ή ήχου) |
| 20 | `set` | Εμφανίζει τις μεταβλητές περιβάλλοντος (LogonServer, Path, ComputerName κ.ά.) | Η τιμή του `LOGONSERVER` δείχνει ποιος Domain Controller πιστοποίησε τον χρήστη, χρήσιμο σε καθυστερήσεις authentication |

## Ασφάλεια & Καλές Πρακτικές

- **Ελάχιστα δικαιώματα:** Εκτελείτε το εργαλείο με αυξημένα δικαιώματα μόνο όταν χρειάζεται.
- **Έλεγχος πριν την εκτέλεση:** Διαβάστε οποιοδήποτε script πριν το τρέξετε σε παραγωγικά συστήματα.
- **Ευαίσθητα δεδομένα:** Οι αναφορές περιέχουν στοιχεία δικτύου και χρηστών (IP, MAC, ονόματα λογαριασμών). Αποθηκεύστε και μοιραστείτε τις μόνο μέσω εγκεκριμένων καναλιών (π.χ. σύστημα ticketing).
- **Προσοχή σε καταστροφικές εντολές:** Οι `taskkill /f`, `chkdsk /r` και `net user` επηρεάζουν άμεσα το σύστημα. Επιβεβαιώστε πάντα τον στόχο πριν την εκτέλεση.
- **Εξουσιοδότηση:** Χρησιμοποιείτε το εργαλείο μόνο σε συστήματα για τα οποία έχετε ρητή άδεια.

## Δεξιότητες που Αναδεικνύονται

- Διάγνωση και επίλυση προβλημάτων Windows (system triage)
- Προχωρημένη χρήση Command Line (CMD / PowerShell)
- Αυτοματοποίηση με PowerShell και δημιουργία αναφορών/logs
- Κατανόηση δικτυακής υποδομής: DHCP, DNS, TCP/IP, Firewalls
- Βασικά στοιχεία Active Directory και Group Policy
- Τεκμηρίωση περιστατικών (ticket documentation)

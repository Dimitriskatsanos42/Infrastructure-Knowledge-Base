# Αυτοματοποίηση Windows Help Desk & Οι 20 Κρίσιμες Εντολές CLI

Καλώς ορίσατε στο αποθετήριο (repository) Υποστήριξης IT και Αυτοματοποίησης. Αυτό το project αποδεικνύει την πρακτική γνώση των λειτουργικών συστημάτων Windows, της διάγνωσης δικτύων και της αξιολόγησης ασφάλειας, δεξιότητες απαραίτητες για ρόλους entry-level Help Desk και Junior SysAdmin.

Αυτό το αποθετήριο περιέχει ένα διαδραστικό **script PowerShell (`HelpDesk-Tool.ps1`)** που αυτοματοποιεί κρίσιμους διαγνωστικούς ελέγχους, καθώς και μια ολοκληρωμένη ανάλυση των **20 κορυφαίων εντολών των Windows** που πρέπει να γνωρίζει κάθε τεχνικός.

---

## 🛠️ Μέρος 1: Το Εργαλείο Αυτοματοποίησης (`HelpDesk-Tool.ps1`)
Το συγκεκριμένο script συγκεντρώνει σύνθετες διαγνωστικές εντολές CLI σε ένα φιλικό προς τον χρήστη, χρωματικά κωδικοποιημένο μενού. Αντί να πληκτρολογεί χειροκίνητα μεμονωμένες εντολές στον υπολογιστή ενός χρήστη, ο τεχνικός μπορεί να τρέξει αυτό το script για να εκτελέσει:
* **Επιλογή 1:** Αυτοματοποιημένη Διάγνωση Δικτύου (`ipconfig`, `ping`, `nslookup`)
* **Επιλογή 2:** Έλεγχος Συστήματος & Δικαιωμάτων Χρήστη (`whoami`, `systeminfo`)
* **Επιλογή 3:** Ενεργές Συνδέσεις Δικτύου (`netstat`)
* **Επιλογή 4:** Έλεγχος Κατάστασης Firewall (`netsh`)
* **Επιλογή 5:** Δημιουργία Αναφοράς (Εξάγει όλα τα αποτελέσματα σε ένα αρχείο `.txt` στην Επιφάνεια Εργασίας για την τεκμηρίωση του ticket υποστήριξης)

## 📚 Μέρος 2: Οι 20 Κορυφαίες Εντολές Windows που Πρέπει να Γνωρίζει Κάθε Τεχνικός Help Desk

Ακολουθεί η τεχνική ανάλυση των 20 πιο κρίσιμων εντολών που χρησιμοποιούνται καθημερινά στην εταιρική υποστήριξη IT, χωρισμένες ανά κατηγορία:

### 🌐 Επίλυση Προβλημάτων Δικτύου (Network Troubleshooting)
1. **`ipconfig /all`**
   * *Τι κάνει:* Εμφανίζει την πλήρη παραμετροποίηση TCP/IP για όλες τις κάρτες δικτύου (IP, Subnet, Gateway, DNS και διευθύνσεις MAC).
   * *Πρακτική Χρήση (Help Desk):* Έλεγχος αν ένα μηχάνημα έλαβε έγκυρη διεύθυνση IP από τον DHCP server ή αν πήρε μια αυτο-εκχωρημένη διεύθυνση APIPA (`169.254.x.x`).
2. **`ping`**
   * *Τι κάνει:* Στέλνει αιτήματα ICMP echo σε μια IP προορισμού ή domain για να ελέγξει τη συνδεσιμότητα και την καθυστέρηση (latency).
   * *Πρακτική Χρήση (Help Desk):* Πληκτρολογούμε `ping 8.8.8.8` για να ελέγξουμε αν το μηχάνημα έχει πρόσβαση στο διαδίκτυο ή `ping όνομα_τοπικού_server` για να ελέγξουμε την εσωτερική συνδεσιμότητα.
3. **`nslookup`**
   * *Τι κάνει:* Ρωτάει τους DNS servers για να βρει τη διεύθυνση IP που σχετίζεται με ένα όνομα χώρου (domain name) ή το αντίστροφο.
   * *Πρακτική Χρήση (Help Desk):* Επίλυση προβλημάτων όταν ένας χρήστης αναφέρει "Δεν μπορώ να ανοίξω την ιστοσελίδα της εταιρείας", ώστε να διαπιστωθεί αν αποτυγχάνει η ανάλυση DNS.
4. **`tracert`**
   * *Τι κάνει:* Καταγράφει τη διαδρομή που ακολουθούν τα πακέτα δεδομένων μέχρι τον προορισμό τους, δείχνοντας κάθε ενδιάμεσο δρομολογητή (hop) από τον οποίο περνούν.
   * *Πρακτική Χρήση (Help Desk):* Εντοπισμός του ακριβούς σημείου όπου η σύνδεση δικτύου πέφτει ή επιβραδύνεται εκτός του τοπικού δικτύου.
5. **`netstat -ano`**
   * *Τι κάνει:* Εμφανίζει όλες τις ενεργές συνδέσεις δικτύου, τις θύρες που "ακούν" (listening ports) και το σχετικό ID της διεργασίας (PID).
   * *Πρακτική Χρήση (Help Desk):* Έλεγχος ασφαλείας για τον εντοπισμό τυχόν κακόβουλου λογισμικού που επικοινωνεί με μη εξουσιοδοτημένη εξωτερική διεύθυνση IP.
6. **`getmac`**
   * *Τι κάνει:* Επιστρέφει τη μοναδική φυσική διεύθυνση MAC των προσαρμογέων δικτύου.
   * *Πρακτική Χρήση (Help Desk):* Παροχή της διεύθυνσης MAC στην ομάδα δικτύων για Port Binding (στατική σύνδεση θύρας) ή για προσθήκη σε λίστα επιτρεπόμενων συσκευών (whitelisting).

### 💻 Διαχείριση Συστήματος & Χρηστών (System & User Management)
7. **`whoami /all`**
   * *Τι κάνει:* Εμφανίζει το όνομα του τρέχοντος συνδεδεμένου χρήστη, τα αναγνωριστικά ασφαλείας (SID) και τις ομάδες (groups) στις οποίες ανήκει.
   * *Πρακτική Χρήση (Help Desk):* Επιβεβαίωση αν ένας τοπικός χρήστης αντιμετωπίζει προβλήματα δικαιωμάτων ή αν ανήκει στην ομάδα των τοπικών Διαχειριστών (Administrators).
8. **`systeminfo`**
   * *Τι κάνει:* Εξάγει μια λεπτομερή αναφορά για την έκδοση του λειτουργικού συστήματος, τα τεχνικά χαρακτηριστικά του υλικού (hardware), τον χρόνο τελευταίας εκκίνησης (boot time) και τις εγκατεστημένες ενημερώσεις ασφαλείας (hotfixes).
   * *Πρακτική Χρήση (Help Desk):* Έλεγχος του "System Boot Time" για να διαπιστωθεί αν ο χρήστης έκανε όντως επανεκκίνηση του υπολογιστή του ή αν απλώς έκλεισε την οθόνη.
9. **`net user`**
   * *Τι κάνει:* Εμφανίζει, δημιουργεί ή τροποποιεί τοπικούς λογαριασμούς χρηστών στο μηχάνημα.
   * *Πρακτική Χρήση (Help Desk):* Η εντολή `net user local_admin *` επιτρέπει τη γρήγορη επαναφορά του κωδικού πρόσβασης ενός τοπικού διαχειριστή χωρίς τη χρήση γραφικού περιβάλλοντος (GUI).
10. **`net localgroup administrators`**
    * *Τι κάνει:* Εμφανίζει όλους τους λογαριασμούς χρηστών που διαθέτουν δικαιώματα διαχειριστή στο τοπικό μηχάνημα.
    * *Πρακτική Χρήση (Help Desk):* Έλεγχος του υπολογιστή για να διασφαλιστεί ότι απλοί χρήστες δεν έχουν αποκτήσει μη εξουσιοδοτημένη πρόσβαση διαχειριστή.
11. **`query user`**
    * *Τι κάνει:* Εμφανίζει πληροφορίες σχετικά με τις ενεργές συνεδρίες (sessions) χρηστών που είναι συνδεδεμένοι στο μηχάνημα (Τοπικά ή μέσω RDP).
    * *Πρακτική Χρήση (Help Desk):* Έλεγχος εάν κάποιος άλλος τεχνικός ή χρήστης είναι ακόμα συνδεδεμένος εξ αποστάσεως πριν γίνει επανεκκίνηση ενός διακομιστή (server).

### 🛠️ Επιδιόρθωση & Συντήρηση Συστήματος (System Repair & Maintenance)
12. **`sfc /scannow`**
    * *Τι κάνει:* System File Checker (Έλεγχος Αρχείων Συστήματος). Σαρώνει όλα τα προστατευμένα αρχεία συστήματος των Windows και επιδιορθώνει τα κατεστραμμένα χρησιμοποιώντας ένα τοπικό αντίγραφο προσωρινής αποθήκευσης (cached copy).
    * *Πρακτική Χρήση (Help Desk):* Επίλυση τυχαίων κρασαρισμάτων των Windows, μπλε οθονών (BSOD) ή λειτουργιών του συστήματος που λείπουν.
13. **`chkdsk /f /r`**
    * *Τι κάνει:* Check Disk (Έλεγχος Δίσκου). Σαρώνει το σύστημα αρχείων του σκληρού δίσκου για σφάλματα (`/f`) και προσπαθεί να ανακτήσει αναγνώσιμες πληροφορίες από κατεστραμμένους τομείς (bad sectors) (`/r`).
    * *Πρακτική Χρήση (Help Desk):* Αντιμετώπιση προβλημάτων σε υπολογιστές που "παγώνουν", σκληρούς δίσκους που κάνουν περίεργους θορύβους ή κατεστραμμένων αρχείων του λειτουργικού συστήματος.
14. **`gpupdate /force`**
    * *Τι κάνει:* Επιβάλλει την άμεση ενημέρωση των Πολιτικών Ομάδας (Group Policies) του Active Directory στο μηχάνημα.
    * *Πρακτική Χρήση (Help Desk):* Άμεση εφαρμογή νέων εταιρικών κανόνων, χαρτογραφημένων δικτυακών δίσκων (mapped drives) ή αναπτύξεων λογισμικού χωρίς να χρειαστεί αποσύνδεση ή επανεκκίνηση του χρήστη.
15. **`gpresult /r`**
    * *Τι κάνει:* Εμφανίζει το Αποτέλεσμα του Συνόλου Πολιτικών (RSoP) για τον χρήστη και τον υπολογιστή.
    * *Πρακτική Χρήση (Help Desk):* Έλεγχος για το ποιες ακριβώς πολιτικές του Active Directory εφαρμόζονται (ή μπλοκάρονται) στο μηχάνημα ενός χρήστη.
16. **`tasklist`**
    * *Τι κάνει:* Εμφανίζει μια λίστα με όλες τις τρέχουσες διεργασίες και τη χρήση μνήμης τους.
    * *Πρακτική Χρήση (Help Desk):* Εντοπισμός κρυφών ή παγωμένων προγραμμάτων που εκτελούνται στο παρασκήνιο και καταναλώνουν το 100% του επεξεργαστή (CPU).
17. **`taskkill /f /im`**
    * *Τι κάνει:* Τερματίζει αναγκαστικά μια ενεργή διεργασία χρησιμοποιώντας το όνομά της (Image Name) ή το PID της.
    * *Πρακτική Χρήση (Help Desk):* `taskkill /f /im outlook.exe` για τον βίαιο τερματισμό μιας παγωμένης διεργασίας του Outlook που αρνείται να κλείσει κανονικά.

### 🛡️ Ρυθμίσεις Ασφάλειας & Περιβάλλοντος (Security & Environment Configuration)
18. **`netsh advfirewall show allprofiles`**
    * *Τι κάνει:* Ελέγχει την κατάσταση (On/Off) των προφίλ του Windows Defender Firewall (Domain, Private, Public).
    * *Πρακτική Χρήση (Help Desk):* Επιβεβαίωση ότι οι πολιτικές ασφαλείας είναι ενεργές και ότι οι χρήστες δεν έχουν απενεργοποιήσει το τείχος προστασίας.
19. **`driverquery`**
    * *Τι κάνει:* Εμφανίζει όλους τους εγκατεστημένους οδηγούς υλικού (drivers) και τις ιδιότητές τους.
    * *Πρακτική Χρήση (Help Desk):* Εντοπισμός παλιών ή ελαττωματικών οδηγών τρίτων κατασκευαστών που προκαλούν δυσλειτουργία στο υλικό (π.χ. αποσυνδέσεις στον ήχο ή στο Wi-Fi).
20. **`set`**
    * *Τι κάνει:* Εμφανίζει τις τοπικές μεταβλητές περιβάλλοντος (Environment Variables) του συστήματος (όπως LogonServer, Path, ComputerName).
    * *Πρακτική Χρήση (Help Desk):* Εύρεση του Domain Controller που επαλήθευσε τον κωδικό πρόσβασης του χρήστη κατά τη σύνδεση, για την αντιμετώπιση προβλημάτων καθυστέρησης ελέγχου ταυτότητας (authentication delays).

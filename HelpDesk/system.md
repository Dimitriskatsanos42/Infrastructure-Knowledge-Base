# 🖧 Windows System & Networking Command Reference
### *Enterprise Troubleshooting & System Administration Guide*

Ο παρών οδηγός αποτελεί ένα ολοκληρωμένο εγχειρίδιο αναφοράς για τη χρήση της Γραμμής Εντολών (**CMD**) και του **PowerShell**. Περιλαμβάνει προηγμένες εντολές για τη διάγνωση δικτύων, τη διαχείριση συστημάτων, τον έλεγχο χρηστών και την αποκατάσταση κρίσιμων σφαλμάτων σε περιβάλλον Windows.

---

## 🌐 1. Δίκτυο & Συνδεσιμότητα (Networking & Triage)

### `ipconfig` (IP Configuration)
Το βασικότερο εργαλείο ελέγχου των διεπαφών δικτύου (Network Interfaces).

* **`ipconfig /all`**
    * **Ανάλυση:** Εμφανίζει τη λεπτομερή δομή όλων των προσαρμογέων (φυσικών και εικονικών). Περιλαμβάνει τη φυσική διεύθυνση (MAC), την κατάσταση του DHCP, τη διάρκεια του Lease, καθώς και τους IPv4/IPv6, Subnet Mask, Default Gateway και DNS Servers.
    * **Use Case:** Ταυτοποίηση λανθασμένων ρυθμίσεων IP (π.χ. static IP conflicts) ή έλεγχος αν ο υπολογιστής πήρε αυτόματη διεύθυνση APIPA (`169.254.x.x`), πράγμα που σημαίνει αποτυχία επικοινωνίας με τον DHCP Server.
* **`ipconfig /release` & `ipconfig /renew`**
    * **Ανάλυση:** Το `/release` στέλνει ένα μήνυμα `DHCPRELEASE` στον server και ακυρώνει την τρέχουσα IP. Το `/renew` στέλνει εκ νέου αίτημα `DHCPDISCOVER` για λήψη νέων ρυθμίσεων.
    * **Use Case:** Άμεση επίλυση IP conflicts ή αναγκαστική ανανέωση ρυθμίσεων μετά από αλλαγές στο εύρος (scope) του DHCP server.
* **`ipconfig /flushdns`**
    * **Ανάλυση:** Εκκαθαρίζει την τοπική προσωρινή μνήμη του DNS Resolver (DNS Cache).
    * **Use Case:** Όταν ένας ιστότοπος άλλαξε πρόσφατα IP διεύθυνση (π.χ. μετά από server migration) αλλά ο υπολογιστής προσπαθεί ακόμα να συνδεθεί στην παλιά, αποτυχημένη IP.

### `ping [host]` (Packet Internet Groper)
* **Ανάλυση:** Στέλνει πακέτα `ICMP Echo Request` στον προορισμό και περιμένει `ICMP Echo Reply`.
* **Use Case:** Επιβεβαίωση βασικής συνδεσιμότητας (Layer 3 του μοντέλου OSI). Αν γίνει ping σε IP (π.χ. `ping 8.8.8.8`) και πετύχει, αλλά αποτύχει στο domain (e.g., `ping google.com`), το πρόβλημα εντοπίζεται αποκλειστικά στον DNS Server.

### `tracert [host]` (Traceroute)
* **Ανάλυση:** Χρησιμοποιεί το πεδίο TTL (Time-to-Live) των πακέτων IP, αυξάνοντάς το σταδιακά κατά 1, για να καταγράψει κάθε router (hop) από τον οποίο περνάει η πληροφορία.
* **Use Case:** Εντοπισμός του ακριβούς σημείου όπου διακόπτεται η σύνδεση (π.χ. αν το πακέτο "κολλάει" στον εσωτερικό router της εταιρείας ή στον πάροχο internet/ISP).

### `nslookup [domain]` (Name Server Lookup)
* **Ανάλυση:** Επιτρέπει την απευθείας υποβολή ερωτημάτων (queries) σε DNS Servers.
* **Pro Tip:** Πληκτρολογώντας σκέτο `nslookup`, εισέρχεσαι σε interactive mode όπου μπορείς να αλλάξεις τον server αναζήτησης γράφοντας `server 1.1.1.1` και να ελέγξεις συγκεκριμένα records (π.χ. `set type=mx` για mail servers).

### `Test-NetConnection [host] -Port [port]`
* **Ανάλυση:** Σύγχρονο cmdlet του **PowerShell** (εναλλακτική του κλασικού Telnet).
* **Use Case:** Έλεγχος αν ένα συγκεκριμένο firewall μπλοκάρει μια θύρα. Για παράδειγμα, η εντολή `Test-NetConnection 192.168.1.50 -Port 3389` επιβεβαιώνει αν η υπηρεσία Remote Desktop (RDP) είναι προσβάσιμη.

### `netstat -ano` (Network Statistics)
* **Ανάλυση:** Απεικονίζει τον πίνακα ενεργών συνδέσεων TCP/UDP. 
    * `-a`: Εμφανίζει όλες τις συνδέσεις και τις θύρες ακρόασης (listening ports).
    * `-n`: Εμφανίζει τις διευθύνσεις και τις θύρες σε αριθμητική μορφή (πιο γρήγορη εκτέλεση).
    * `-o`: Εμφανίζει το Process ID (PID) που αντιστοιχεί σε κάθε σύνδεση.
* **Security Use Case:** Αν εντοπιστεί μια άγνωστη εξωτερική σύνδεση σε κατάσταση `ESTABLISHED`, χρησιμοποιούμε το PID για να βρούμε μέσω του Task Manager ποιο ακριβώς εκτελέσιμο αρχείο (exe) την προκάλεσε (πιθανή ένδειξη malware).

### `ncpa.cpl`
* **Ανάλυση:** Συντόμευση ελέγχου συστήματος (Control Panel Applet). Ανοίγει ακαριαία το GUI διαχείρισης των Network Adapters, παρακάμπτοντας τα πολλαπλά μενού των Windows 10/11 Settings.

### `networkreset`
* **Ανάλυση:** Ριζική επανεγκατάσταση όλων των network adapters και επαναφορά των στοιχείων δικτύωσης (TCP/IP stack) στις εργοστασιακές ρυθμίσεις.
* **⚠️ Προσοχή:** Διαγράφει αποθηκευμένους κωδικούς Wi-Fi και ρυθμίσεις VPN. Απαιτείται επανεκκίνηση εντός 5 λεπτών.

## 👤 2. Διαχείριση Χρηστών & Ταυτοποίησης (Identity & Access Management)

### `net use`
* **Ανάλυση:** Συνδέει, αποσυνδέει και εμφανίζει πληροφορίες για κοινόχρηστους πόρους (Shared Folders/Drives) σε περιβάλλον SMB δικτύου.
* **Παράδειγμα:** `net use Z: \\ServerName\SharedFolder /user:Administrator Password123` (Αντιστοιχίζει έναν δικτυακό φάκελο ως δίσκο Z: με συγκεκριμένα διαπιστευτήρια).

### `net user` & `net localgroup`
* **Ανάλυση:** Εργαλεία διαχείρισης της τοπικής βάσης δεδομένων χρηστών (SAM - Security Accounts Manager).
* **`net user [username]`**: Εμφανίζει πότε άλλαξε κωδικό ο χρήστης, πότε λήγει ο κωδικός του και σε ποιες ομάδες ανήκει.
* **`net localgroup administrators`**: Εμφανίζει ποιοι λογαριασμοί έχουν πλήρη δικαιώματα root/admin στο μηχάνημα. Κρίσιμο για ελέγχους ασφαλείας (Privilege Escalation audits).

### `whoami /groups`
* **Ανάλυση:** Εμφανίζει τα Access Tokens και τα SIDs (Security Identifiers) του τρέχοντος session.
* **Use Case:** Επιβεβαίωση αν ένας χρήστης έχει λάβει σωστά τα δικαιώματα ενός Security Group στο Active Directory μετά από αλλαγή που έγινε από τον SysAdmin (απαιτεί log-out/log-in).

### `hostname` & `echo %computername%`
* **Ανάλυση:** Επιστρέφουν το NetBIOS όνομα του σταθμού εργασίας.
* **Use Case:** Απαραίτητο κατά την απομακρυσμένη υποστήριξη (Helpdesk) για να γνωρίζει ο τεχνικός σε ποιο μηχάνημα πρέπει να συνδεθεί μέσω RDP ή Deployment tools.

### `systeminfo`
* **Ανάλυση:** Συλλέγει δεδομένα υλικού (Hardware) και λογισμικού (Software).
* **SysAdmin Tip:** Ιδιαίτερα χρήσιμο για τον έλεγχο της ημερομηνίας εγκατάστασης του OS (`Original Install Date`) και του `System Boot Time` για να διαπιστωθεί αν ο χρήστης έκανε όντως επανεκκίνηση (Reboot) ή απλό Shutdown (λόγω του Windows Fast Startup).

## ⚙️ 3. Διαχείριση Διεργασιών (Process Management)

### `tasklist`
* **Ανάλυση:** Καταγράφει όλες τις ενεργές διεργασίες στη μνήμη RAM.
* **Advanced Σύνταξη:** `tasklist /FI "MEMUSAGE gt 100000"` (Φιλτράρει και εμφανίζει μόνο τις διεργασίες που καταναλώνουν πάνω από 100MB μνήμης).

### `taskkill`
* **Ανάλυση:** Τερματίζει βίαια (kill) threads και processes.
    * `/PID`: Καθορίζει τη διεργασία βάσει του μοναδικού της αριθμού.
    * `/F`: Force (αναγκαστικός τερματισμός, αγνοώντας prompts για αποθήκευση).
* **Εναλλακτική (by Name):** `taskkill /IM chrome.exe /F` (Κλείνει όλα τα ανοιχτά instances του Google Chrome).

## 🛡️ 4. Πολιτικές Ομάδας (Group Policy Triage)

Σε εταιρικά περιβάλλοντα (Active Directory Domains), οι ρυθμίσεις ασφαλείας καθορίζονται από τα Group Policies (GPOs).

| Εντολή | Μορφή Αρχείου | Σκοπός / Χρήση |
| :--- | :--- | :--- |
| **`gpupdate /force`** | - | Παρακάμπτει το προκαθορισμένο refresh interval (90-120 λεπτά) και εφαρμόζει αμέσως τις νέες πολιτικές από τον Domain Controller. |
| **`gpresult /r`** | Κείμενο (CMD) | Εμφανίζει συνοπτικά ποια GPOs εφαρμόστηκαν επιτυχώς (Applied GPOs) and ποια απορρίφθηκαν λόγω φίλτρων (Filtered Out). |
| **`gpresult /h report.html`** | HTML | Παράγει μια πλήρη, γραφική και λεπτομερή αναφορά. Ανοίγει σε browser και επιτρέπει στους Μηχανικούς Δικτύων να κάνουν deep-dive debugging σε αντικρουόμενες πολιτικές. |

## 🧰 5. Ακεραιότητα & Επισκευή Συστήματος (System Lifecycle & Maintenance)

Όταν το λειτουργικό σύστημα παρουσιάζει αστάθεια, Blue Screens (BSOD) ή κατεστραμμένα αρχεία, η διαδικασία αποκατάστασης ακολουθεί μια **συγκεκριμένη ιεραρχία**:

```
[Βήμα 1: DISM] ──> Επισκευή του Τοπικού Ειδώλου (Component Store) μέσω Windows Update
       │
       ▼
[Βήμα 2: SFC]  ──> Σάρωση & Αντικατάσταση Κατεστραμμένων Αρχείων Συστήματος
```

### 1. `dism /online /cleanup-image /restorehealth`
* **Ανάλυση:** Το Deployment Image Servicing and Management (DISM) ελέγχει το Component Store (`C:\Windows\WinSxS`) για αλλοιώσεις. Συγκρίνει τα αρχεία με τα επίσημα αρχεία των servers της Microsoft (ή του WSUS) και διορθώνει το είδωλο των Windows.
* **Γιατί προηγείται:** Αν το ίδιο το είδωλο-πηγή είναι κατεστραμμένο, η εντολή `sfc` δεν θα μπορεί να βρει υγιή αρχεία για να κάνει την αντικατάσταση.

### 2. `sfc /scannow`
* **Ανάλυση:** Το System File Checker (SFC) σαρώνει όλα τα κρίσιμα προστατευμένα αρχεία συστήματος (π.χ. .dll, .exe). Αν εντοπίσει αλλοιώσεις, τα αντικαθιστά χρησιμοποιώντας τα υγιή αρχεία που επιδιορθώθηκαν μόλις από το DISM.
* **Αποτέλεσμα:** Τα logs της καταγραφής αποθηκεύονται στο αρχείο `C:\Windows\Logs\CBS\CBS.log` για περαιτέρω ανάλυση.
